## How to read the tables

- A time is the median wall clock time of the runs that found a solution, followed by how many of the runs did (for example `1.90 s (5/5)`).
- `no solution` means no run found a solution within the time limit. A cell stops early after two runs in a row time out.
- `error: ...` means the solver crashed with that exception when it was run. A cell stops early after two runs in a row fail.
- `n/a` means that version of the library has no such algorithm, or the case was not run.
- Tantrix variants use the first N tiles in numeric order. Each repetition seeds the shared random generator, but the Tantrix simulated annealing and global hill climbing solvers create their own unseeded generator, so their timings vary from run to run.
